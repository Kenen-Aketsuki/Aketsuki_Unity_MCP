# 工程客制化专区（不进包）

本目录下的所有文件是**单个工程专属**的指令系统客制化内容：依赖该工程运行期代码，
**不能用在本仓库**（本仓库没有运行期代码）。实际使用时，在目标工程里把客制化内容放这里。

**铁律：本目录绝不打进 `.unitypackage`**（`Tools/build_unitypackage.py` 强制排除，
`Tools/verify_unitypackage.py` 对成品包断言）。详见上级目录 README「工程客制化内容」一节。

约束：
- 上级通用代码（Core/ Commands/ 等）不得引用本目录内的类型；
- 本目录可以自由引用通用类型与工程运行期类型；
- 打进包里的内容必须保持对工程零编译依赖。

（占位说明文件本身也属于本目录，同样不进包。）
